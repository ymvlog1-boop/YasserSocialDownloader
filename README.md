# Yasser Social Downloader

الإصدار 1.2.2 — مجلد مستقل لكل بروفايل وفيديو إنستغرام بصوت مدمج دون ملفات صوت منفصلة.

تطبيق Windows عربي باستخدام PySide6، مع yt-dlp وgallery-dl وFFmpeg.

## الاستخدام

1. فك ضغط الحزمة كاملة إلى مجلد على جهازك.
2. افتح `YasserSocialDownloader.exe`. احتفظ بمجلد `_internal` بجواره.
3. ألصق رابطًا أو عدة روابط، كل رابط في سطر، ثم اضغط **تحميل الآن**.
4. المحتوى الذي يحتاج جلسة دخول: افتح **إدارة الكوكيز** واختر ملف Netscape cookies.txt للمنصة، ثم فعّل **استخدام ملف الكوكيز** قبل الإضافة.

لا يحتاج المستخدم إلى Python أو الطرفية. البرنامج لا يطلب كلمات مرور.

## السلوك والحدود

- إنستغرام وإكس وفيسبوك وتيك توك: الوضع التلقائي والصور وجميع الوسائط تستخدم gallery-dl، بينما وضع الفيديو الصريح يستخدم yt-dlp لاختيار الجودة.
- روابط البروفايلات تُحفظ تلقائيًا داخل `المنصة/اسم_المستخدم` لمنع اختلاط ملفات الحسابات المختلفة.
- إنستغرام يحفظ الصور والفيديو فقط. يطلب الفيديو المدمج بالصوت ويعطّل مرفقات الصوت المنفصلة مثل `.m4a`.
- فيسبوك في الوضع التلقائي/جميع الوسائط يجري مرورًا إضافيًا عبر yt-dlp بعد gallery-dl لمحاولة جلب فيديوهات الحساب أيضًا.
- إضافة إلى القائمة تحفظ المهمة موقوفة حتى تختار الاستكمال. تحميل الآن يشغّل المهام حسب حد التزامن (1–4، الافتراضي 2).
- الإيقاف يوقف العملية. الاستكمال يعيد تشغيل المحرك مع الملفات الجزئية والأرشيف؛ بعض المواقع تعيد بدء الملف الحالي. لا يُدّعى استكمال كل ملف من البايت نفسه.
- النسبة تخص الملف الحالي عند معرفة حجمه. لا يعرض البرنامج نسبة إجمالية وهمية للحسابات. gallery-dl يعرض مؤشرًا غير محدد وعدد الملفات المكتملة.
- المهام الجارية عند إغلاق البرنامج تُحفظ موقوفة. سجل SQLite والإعدادات في `%LOCALAPPDATA%/YasserSocialDownloader`.
- لا تعرض الواجهة محتويات الكوكيز. الفحص المحلي يتحقق من الصيغة والمنصة والصلاحية الزمنية، ولا يؤكد قبول الموقع للجلسة.
- يتلقى المحرك نسخة مؤقتة من ملف الكوكيز، تُحذف عند انتهاء المهمة. يبقى الملف الأصلي دون تعديل. تُنظّف النسخ المؤقتة المتبقية عند التشغيل التالي بعد أي انقطاع.
- تُحفظ أسماء الملفات العربية والإيموجي بترميز UTF-8. تُسجّل مسارات الملفات المكتملة أثناء المهمة، ولا تُعلَن مهمة بلا ملفات على أنها تنزيل ناجح.
- الوضع التلقائي لإنستغرام وإكس يحاول محرك الفيديو أيضًا إذا فشل gallery-dl أو لم يُرجع وسائط. وضع الصور لا يتحول إلى تنزيل فيديو.
- خيار صوت فقط يستخرج ملف MP3 بواسطة FFmpeg.
- عند فشل المصادقة: غيّر الملف من إدارة الكوكيز، أو غيّر وضع الكوكيز للمهمة ثم اضغط إعادة المحاولة.
- الحماية من التكرار تعتمد على الروابط المحفوظة وأرشيف المحرك والملفات الموجودة. خيار فرض إعادة التنزيل يتجاوزها.
- تحديث المحركات يستخدم yt-dlp الرسمي وبناء gallery-dl الليلي الموثوق من gdl-org مع SHA-256 المنشور. إذا لم تتوفر بصمة يرفض التحديث ويحتفظ بالنسخة الحالية. تحديث التطبيق نفسه يتم باستبدال حزمته يدويًا.
- يتحقق التحديث من الإصدارات الحالية أولًا؛ لا يعيد تنزيل الإصدار نفسه ولا يخفض الإصدار. إذا فشل تحديث أحد المحركين فلا يفعّل تحديثًا جزئيًا.
- النسخة غير موقعة رقميًا. لم تُختبر على تثبيت Windows 10/11 نظيف مستقل عن جهاز البناء.

## التطوير والبناء

Python 3.11 x64. تثبيت `requirements.txt` ثم تشغيل `python main.py`.
للاختبار: `python -m unittest discover -s tests -v` ثم `python tests/integration.py` و`python tests/resume_integration.py`.
للبناء: `python build.py`. ينتج مجلد `dist/YasserSocialDownloader`.
لا تحتاج PySide6 Addons للتطبيق؛ يعتمد على QtCore/QtGui/QtWidgets الموجودة في Essentials.

الهيكل: `app/core.py` للتحقق والتخزين، `backend.py` لبناء أوامر المحركات، `manager.py` للعمليات والحالات، `updater.py` للتحديثات، `ui.py` للواجهة.
