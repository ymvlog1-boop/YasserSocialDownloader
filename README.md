# YasserSocialDownloader

تطبيق Windows عربي لتنزيل الوسائط من المنصات المدعومة، مع وضع مستقل للروابط المباشرة التي يزوّدها المستخدم.

## الروابط المباشرة

فعّل **روابط مباشرة لملفات صور أو فيديو (HTTPS)** في الصفحة الرئيسية، ثم ألصق رابط الملف نفسه، كل رابط في سطر. يقبل الوضع استجابات الصور والفيديو المدعومة فقط؛ لا يستخرج وسائط من صفحة ويب أو حساب، ولا يستخدم الكوكيز. استخدمه للمحتوى الذي تملك حق تنزيله.

يحفظ الملف الجزئي لاستكماله بطلب Range عندما يدعم الخادم ذلك. إذا تجاهل الخادم Range يبدأ الملف من الصفر. يتجنب إعادة تنزيل الرابط المكتمل ما دام الملف موجودًا، ويمكن اختيار **فرض إعادة التنزيل** للتجاوز. أسماء الملفات تتضمن بصمة للرابط لمنع تصادم الملفات المتشابهة.

## البناء

يستعيد GitHub Actions مصدر الإصدار الأساسي من `bootstrap/`، ويطبق الرقع القديمة، ثم ينسخ مصدر الإصدار 1.3.0 من `overlays/direct/`. يشغّل الاختبارات ويبني حزمة Windows وينشرها في Releases عند نجاح العمل على الفرع الرئيسي.
